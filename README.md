# 🏸 Badminton Dashboard

A badminton dashboard project using data scraped from the Badminton World Federation (BWF) Website.

## Project Overview

* Scraped **5,000+ match and player records** covering 6 years
* Cleaned and processed the data using Python
* Built an interactive Tableau dashboard to explore player and match performance

## Dashboard

![Badminton World Federation Dashboard](image/dashboard.png)

## Dashboard Features

* Overall tournament statistics
* Win rates by Country
* Top 10 players
* Biggest upsets
* Head to Head

## Data Pipeline

```text
BWF Website
    ↓
Web Scraping
    ↓
Data Cleaning
    ↓
Relational SQL Database
    ↓
Tableau Dashboard
```
